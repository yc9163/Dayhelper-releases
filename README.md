# DayHelper 小助手 · 桌面版下载

这里只放 DayHelper 小助手 Windows 桌面版的**安装包和自动更新文件**（源代码不在这里）。

## 下载

到 [Releases](https://github.com/yc9163/Dayhelper-releases/releases/latest) 下载最新的 `DayHelper-Setup-<版本>.exe`，
双击安装。需要 Windows 10 / 11（64 位）。

也可以不安装，直接用网页版：<https://dayhelper.yunkangchen2017.workers.dev>

## 安装时被拦住了？

安装包没有购买 Windows 代码签名证书，第一次安装时可能看到：

1. 浏览器提示「不常下载」：在下载列表里点「…」→「保留」。
2. 「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。

图文说明：<https://dayhelper.yunkangchen2017.workers.dev/download>

## 自动更新

装好后 DayHelper 会自动检查这里的新版本。每个版本都附带开发者的签名文件（`.sig`），应用验证通过才会安装。
